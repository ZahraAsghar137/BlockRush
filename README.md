# 🎮 BlockRush

**BlockRush** is a Python-based Tetris-style game developed using **Pygame** as a programming project. The game applies programming fundamentals and game-development concepts to create an interactive block-stacking experience.

## 🚀 Features

* 🎮 Interactive gameplay
* 🧱 Falling blocks
* ↔️ Block movement
* 🔄 Block rotation
* 💥 Collision detection
* 🧹 Line clearing
* 🏆 Score tracking
* 🎯 Real-time keyboard controls

## 🛠️ Technologies Used

* **Python**
* **Pygame**

## 🎯 Project Objectives

* Apply Python programming fundamentals in a practical project.
* Understand game loops and event handling.
* Implement collision detection and movement logic.
* Practice functions, loops, conditional statements, and data structures.
* Develop problem-solving skills through interactive game development.

## ▶️ How to Run

### 1. Install Python

Make sure Python is installed on your computer.

### 2. Install Pygame

Open the terminal and run:

```bash
pip install pygame
```

### 3. Run the Game

Navigate to the project folder and run:

```bash
python BlOCKRUSH_MAIN.py
```
